## 决定结论强度的三点

1. **pC1 长 IPI 衰减依赖读出方式。** 100 ms 峰值读出满足 35 ms 高于 85/95 ms；但净累计放电数/神经元/脉冲在 35、85、95 ms 下为 0.3873、0.4866、0.4996，方向相反。当前无法声称模型已稳定复现带通调谐。
2. **vPN1 的特异性因果作用证据弱。** 35 ms 时 vPN1 消融使 pC1 累计放电下降 3.80%，低于匹配随机对照中位数 7.18%（95 分位 16.30%；19/24 个随机对照的下降不少于 vPN1 消融）。同时 pC1 峰值反而增加约 15.65%。因此“累计放电严格下降”的核心方向条件虽然成立，但不足以支持强必要性结论。
3. **pC1 的下游影响较明确，仍不能等同于行为复现。** 35 ms 时 pC1 消融使 pIP10 累计放电下降 89.91%，pMP2 下降 100%；对应随机对照 95 分位为 41.65% 和 88.89%。这支持其在当前模型中影响输出；随机样本不是独立动物试验，不能据此报出生物学显著性。

另外，pC1 在 35 ms 对比 25 ms 的峰值优势不足 1%，这里只满足数值方向，不能当作实验显著差异。pIP10、pMP2 与 chaining 行为之间尚无已验证的定量映射；合并输出只作探索性统计。旧警告所代表的问题仍保留。
