# CNS2FPGA CPU Floating-Point Golden Model

This directory implements project step 3: a deterministic floating-point LIF
reference model driven directly by the intermediate representation generated by
step 2.

The model is a **connectome-constrained computational reference**, not a claim
that generic LIF dynamics reproduce the biological fly CNS. Its purpose is to
freeze explicit execution semantics before fixed-point conversion and RTL work.

## Model semantics

For neuron `i` at discrete timestep `t`:

```text
V_i[t+1] = exp(-dt/tau_m) * V_i[t] + I_syn_i[t] + I_ext_i[t] + bias
spike_i[t] = V_i[t+1] >= threshold
```

- Spikes have a one-timestep synaptic delay.
- Spiking neurons reset to `reset_voltage` and enter a configurable refractory period.
- Connectivity and synapse counts come from step 2 without topology changes.
- The frozen courtship configuration linearly weights aggregate synapse counts;
  it does not normalize away postsynaptic input strength.
- Acetylcholine is `+1`, GABA and glutamate are `-1`; unresolved/modulatory
  transmitters remain `0`.
- Random noise defaults to zero; a fixed seed is recorded when enabled.

The courtship gain (`0.015`) is the lowest tested point at which aPN1, vPN1,
pC1, pIP10 and pMP2 all respond in the 36-ms condition under this sign policy.
It is a calibrated reference parameter, not a membrane-voltage unit or a claim
about absolute biological firing rate.

## Layout

- `configs/` — model, stimulus and observation definitions.
- `src/cns2fpga_golden/` — simulator, stimuli and result analysis.
- `run_golden_model.py` — experiment runner.
- `sweep_recurrent_gain.py` — diagnostic gain sweep used to avoid silent/explosive regimes.
- `tests/` — deterministic unit tests on small networks.
- `outputs/` — generated simulation results.

## Run

From this directory:

```powershell
python run_golden_model.py --config configs/courtship_song_lif_v0.json
```

Each condition produces compressed spike events, population activity and selected
membrane traces. `summary.csv` and `report.md` compare all IPI conditions.

The V0 recurrent gain is frozen at `8.0`: it is the lowest tested value that
activated both pC1 and the pIP10/pMP2 descending outputs under the middle-IPI
condition. This is a numerical operating-point choice, not a fitted biological parameter.
